# Kigali Kitchen

A 30-day meal plan and grocery checklist for one person in Kigali, shopping at Simba and Spar.

- 3 meals + 2 snacks a day, halal (chicken & beef), no fish
- Mediterranean, Middle Eastern and Asian stir-fry recipes, each with a photo
- 1 big shop + 3 small weekly top-ups, with pack counts, estimated prices (RWF) and replacements if an item is missing
- Works offline and can be added to a phone home screen

Plain HTML/CSS/JS, no build step. Edit `data.js` to change ingredients, prices, recipes or the plan.

Recipe photos: [TheMealDB](https://www.themealdb.com) (illustrative). Prices are estimates.
